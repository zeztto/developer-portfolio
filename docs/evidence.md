## 공개 코드 목록

[공개 코드](public-code.md)는 GitHub에서 공개된 저장소와 현재 default branch의 head, 같은 head에서 성공한 GitHub Actions를 확인한 목록입니다. [공개 코드 metadata](../data/public-code-projects.json)에는 공개 이름·용도·저장소·head·CI와 권리 고지 위치만 담습니다. 문서 저장소인 이 repository는 코드 프로젝트 수에서 제외합니다.

서비스 소개 아카이브의 항목 수와 공개 코드 저장소 수는 서로 다른 집계입니다. source 공개·CI 성공과 실제 호스팅 서비스의 배포·운영, 장치·DAW·확장의 설치 검증도 별도로 읽어야 합니다. 구체적인 검사와 제한은 각 저장소의 문서를 연결했습니다.

## 구현 설명과 확인 범위

구현 설명은 공개 소개와 작성 당시 manifest·선별 구현을 읽은 기록에 근거합니다. LMML, p1zza.kr, 갈릭톤 스튜디오, circlr, MixManifest, AAF Trans, Drum Editor, Realtime Restore, YAMMY, WP Manager에서 import, API·작업자 초기화, ORM, 파일·오디오 처리 모듈과 주요 기술의 연결을 살폈습니다.

**공개 소개와 선별 코드 확인은 제품 전체의 최신 빌드·테스트·배포·실행 검증이 아닙니다.** 이 문서 작업에서 제품을 모두 재실행하지 않았으며, 공개 URL의 접근 가능성만으로 최신 수정의 운영 반영이나 Google 색인 완료를 판단하지 않습니다. 제품별 포맷·장치·host 지원에 관한 중요한 범위는 [대표 사례](case-studies.md)에 적었습니다.

제품 source는 이 문서 저장소에 포함하지 않고 공개 코드 목록의 각 저장소로 연결합니다. 공개 source 링크가 없는 구현 설명은 이 문서만으로 독립 재현할 수 없는 범위입니다. 문서 검사도 링크·스냅샷·버전의 정합성과 기본 공개 안전성을 다루는 검사입니다.

## 이력과 수치

공개 프로필에서 확인할 수 있는 배경만 사용합니다. 회사·고객·재직 기간·직함·연차·학위·자격·수상이나 매출·사용자 수는 추정하지 않습니다. 전체 목록의 항목 수는 납품 건수·고객 수·독립 원작 수가 아니며, 기술 표기의 수 역시 각 기술의 숙련도를 뜻하지 않습니다.

UI 구현이나 SDK 사용은 해당 범위로 설명합니다. 화면 구현을 외부 거래·업무의 실제 처리나 인증 실적으로, AI API 연동을 모델 학습·대규모 GPU 운영 경험으로 확대하지 않습니다.

## 출처와 권리

외부 parser·라이브러리와 upstream을 바탕으로 한 작업은 원본과 추가 구현을 함께 밝힙니다. MixManifest의 logicxkit 참고·이식 관계는 [대표 사례](case-studies.md)에, ECC 기반 workflow 확장은 [개발·검증 방식](engineering.md)에 있습니다. 이를 독자 창작이나 upstream 기여 실적으로 표시하지 않습니다.

이 저장소는 포트폴리오 문서이며 제품 코드에 새 라이선스를 부여하지 않습니다. 프로젝트와 외부 기술의 권리·라이선스는 각 원저작자에게 있습니다. 외부 제품·기술의 언급은 해당 조직과의 고용·제휴·보증 관계를 뜻하지 않습니다. 문서 구조를 참고한 출처는 [참고와 출처](references.md)에 정리했습니다.

## 공개 자료의 범위와 정정

개인·고객 데이터, 비공개 저장소명·URL, 관리자 자료, 운영 로그·DB·서버 경로·계정·계약·자격 증명은 포함하지 않습니다. 기존 제품의 공개 여부도 이 문서 저장소로 인해 바뀌지 않습니다.

오류는 GitHub Issue로 정정 요청할 수 있습니다. 비밀번호·인증 코드·고객 데이터 등 민감한 자료는 첨부하지 마세요.
