공개 목록에서 `isPublished`가 참인 항목의 id·이름·짧은 설명·분류·기술명만 선별해 [스냅샷](../data/public-projects.json)에 담습니다. 연락처·이미지·운영 로그·계정 정보·저장소 URL은 복사하지 않습니다.

## 구현 교차 확인

LMML, p1zza.kr, 갈릭톤 스튜디오, circlr, MixManifest, AAF Trans, Drum Editor, Realtime Restore, YAMMY, WP Manager의 manifest·선별 구현을 읽고 주요 기술 연결을 확인했습니다. native 파일의 import, API·작업자의 초기화, ORM과 저장소·오디오 처리 모듈 등을 확인한 수준입니다.

원본 소스가 비공개인 경우 이 저장소에 코드·파일 경로·비공개 저장소명·commit URL을 넣지 않습니다. 따라서 **공개 독자는 이 문서만으로 비공개 구현을 독립 재현할 수 없습니다.** 공개 설명과 작성 시 확인 사실을 구분해서 읽어주세요. 이번 작성에서 제품 전체의 빌드·테스트·배포를 재실행하지 않았습니다.

## 이력의 서술 기준

- 회사·고객·재직 기간·직함·연차·학위·자격·수상·매출·사용자 수를 추정하지 않습니다.
- 프로젝트 목록의 항목 수를 납품 건수·고객 수·독립 원작 수로 바꾸지 않습니다.
- 화면 UI 구현을 결제·의료·금융 업무의 실제 처리나 법적 인증으로 확대하지 않습니다.
- SDK 사용을 foundation model 학습·대규모 GPU 운영으로 표현하지 않습니다.
- AI-assisted 작업도 검토·검증의 책임과 미확인 경계를 남깁니다.
- upstream·fork·외부 parser·SDK·라이브러리 사용을 독자 개발이나 upstream 기여 실적으로 표시하지 않습니다.

## 공개하지 않는 항목

비공개 고객·서비스, 관리자 화면·원문 로그·DB, 내부 hostname·IP·서버 경로·계정·계약, 비밀번호·token·인증 코드는 포함하지 않습니다. 기존 프로젝트의 공개 여부나 라이선스를 이 저장소 생성 때문에 바꾸지 않습니다.

## 문서와 권리

이 저장소는 개인 포트폴리오 문서이며 제품 소스의 공개 저장소가 아닙니다. 별도의 오픈소스 라이선스를 제품 코드에 부여하지 않습니다. 프로젝트와 외부 기술의 권리·라이선스는 해당 원저작자에게 있습니다. 참고 문서의 문구·로고·배지·star 수는 복제하지 않았습니다.

오류는 GitHub Issue로 정정 요청할 수 있습니다. 민감한 자료를 증거로 공개하지 마세요. 공개 열람이 가능한 문서라는 사실과 원본 제품의 코드 접근 권한은 별개입니다.
