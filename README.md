## 대표 웹사이트

### LMML 공연 정보 서비스

Next.js·React·TypeScript로 공연 일정과 라인업을 보여주는 공개 화면과 공연 정보 관리 화면을 구현했습니다. 다국어 라인업을 편집한 뒤 다시 열어 저장된 값을 확인하고, 공개 화면의 표시와도 비교했습니다. API는 Next.js Route Handlers, 데이터 저장은 Drizzle ORM과 SQLite를 사용합니다. [서비스 열기](https://lmml.kr/) · [구현 사례](https://p1zza.kr/portfolio/lmml)

### p1zza.kr 개인 포트폴리오

React·Vite로 프로젝트 목록·상세 화면을 만들고, Express·Drizzle ORM·PostgreSQL로 구성한 공개 API를 연결했습니다. 데이터를 불러오는 중과 요청이 실패했을 때의 화면을 처리했습니다. 프로젝트 링크와 스크린샷을 갱신한 뒤 PC와 모바일에서 상세 화면을 거쳐 실제 서비스로 이동할 수 있는지 확인했습니다. [홈페이지](https://p1zza.kr/) · [프로젝트 목록](https://p1zza.kr/portfolio)

### 갈릭톤 스튜디오

Next.js와 Payload CMS로 음반·서비스·공간 정보를 관리하고, 한국어·영어 페이지에 연결했습니다. [사이트 열기](https://www.garlicton.com/ko) · [구현 사례](https://p1zza.kr/portfolio/garlicton)

### OFIS

Next.js·React·TypeScript로 디지털 자산 가치 평가 서비스 소개와 매물 탐색 화면을 구성한 웹사이트입니다. [사이트 열기](https://ofis.kr/) · [구현 사례](https://p1zza.kr/portfolio/ofis)

## Codex 활용과 검증

Codex에 구현할 기능과 수정 범위, 화면에서 확인할 동작을 먼저 전달합니다. 변경된 코드를 직접 읽고 테스트한 뒤, PC와 모바일에서 실제 사용 흐름을 확인합니다. LMML에서는 라인업을 편집하고 다시 열었을 때의 값을 공개 화면과 비교했습니다. p1zza.kr에서는 프로젝트 목록에서 상세 화면을 거쳐 실제 서비스가 열리는지 확인했습니다. [개발·검증 방식](docs/engineering.md)
